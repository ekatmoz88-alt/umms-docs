# Печать документов
*Printing Documents*

> **Статус: Draft / Черновик.** Пользовательский сценарий описан по тексту руководства; поведение интерфейса ещё требуется проверить.

| Параметр | Значение |
|---|---|
| Система | «Стационарная станция» |
| Раздел | Работа с документами |
| Точка входа | Главное окно приложения |
| Основное действие | Кнопка «Печать» |

## 1. Описание

Любой документ может быть представлен в готовом для печати виде.

Для этого в главном окне программы «Стационарная станция» необходимо нажать кнопку **«Печать»**. После этого открывается новое окно, содержащее печатную форму документа, которую можно отправить на печать.

## 2. Последовательность действий

| Шаг | Действие | Результат |
|---|---|---|
| 1 | Открыть документ в главном окне программы | Документ активен |
| 2 | Нажать кнопку «Печать» | Открывается новое окно с печатной формой |
| 3 | Отправить печатную форму на печать | Документ отправлен на выбранное устройство печати |

## 3. Проверка перед окончательной публикацией

- [ ] Проверено, что кнопка называется именно «Печать» во всех поддерживаемых локалях.
- [ ] Проверены доступные команды нового окна: печать, предварительный просмотр, сохранение в PDF.
- [ ] Проверено, для каких типов документов формируется печатная форма и существуют ли исключения.
- [ ] Проверено, требуется ли предварительно сохранять документ перед печатью.

## 4. Границы описания

Этот раздел фиксирует только пользовательский сценарий, описанный в руководстве. Он не утверждает наличие встроенной команды экспорта в PDF, отдельного режима предварительного просмотра или универсальной поддержки всех типов документов: эти детали требуют проверки в работающем приложении.

Внутренняя реализация формирования печатной формы, используемые библиотеки и механизм взаимодействия с принтером в рамках этого раздела не документированы.

## 5. Редакционное примечание

Раздел относится к системе «Стационарная станция» и ведётся отдельно от документации Global11 / Oracle Data Modeler. Одинаковый статус Draft у этих материалов отражает разные основания для проверки: для печати — сверка с интерфейсом приложения и пользовательским руководством.
