1. API — описание интерфейсов

Система предоставляет программный интерфейс для поиска физических лиц, получения их документов, адресов и дел, а также для выпуска и отката документов.

Методы

№МетодНазначениеВходВыход
1searchPersonFileПоиск лиц по критериямДаты, пол, ФИОСписок лиц
2getPersonDocumentsПолучение документов лицаИдентификатор лицаСписок документов
3getPersonAddressesПолучение адресов лицаИдентификатор лицаСписок адресов
4getPersonCasesInfoПолучение дел лицаИдентификатор лицаСписок дел
5getDocumentDetailДетали документаИдентификатор документаДетальная информация
6getAddressDetailДетали адресаИдентификатор адресаДетальная информация
7getCountryDictionaryСправочник стран—Список стран
8issueNewDocumentВыпуск документаДанные для выпускаРезультат операции
9rollbackIssueNewDocumentОткат выпускаИдентификатор документаРезультат операции

Типы данных (кратко)

  • Лицо: ФИО, дата рождения, пол, идентификатор
  • Документ: серия, номер, даты, кем выдан, тип
  • Адрес: код ФИАС, текстовое представление, тип
  • Справочник: код, значение

Пример структуры запроса (абстрактно)

Метод: searchPersonFile
Параметры: дата от, дата до, пол, фамилия
Формат: SOAP 1.1 / 1.2
Детали: предоставляются по NDA

Примечания

  • Протокол взаимодействия: SOAP
  • Адрес сервиса и учётные данные предоставляются отдельно
  • Поддерживается постраничный вывод результатов поиска

2. Клиент — описание системы

Программный комплекс для автоматизации работы с досье физических лиц и выпуска документов.

Состав

МодульОбозначениеНазначение
СтационарныйССРабота в локальной сети с постоянным доступом к сервису
МобильныйМСАвтономная работа с последующей синхронизацией

Основные функции

  • Поиск и просмотр досье физических лиц
  • Управление документами и адресами
  • Выпуск документов по установленным сценариям
  • Обмен данными между СС и МС (автономный режим)
  • Работа со справочниками (стран, адресов ФИАС)

Технологии

  • Платформа: Windows, .NET
  • Интерфейс: WPF
  • Обмен данными: зашифрованные файлы, цифровая подпись
