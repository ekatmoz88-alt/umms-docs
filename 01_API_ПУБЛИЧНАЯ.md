# API УММС — описание интерфейсов

> Общедоступная версия. Подробная техническая документация предоставляется по запросу в рамках соглашения о конфиденциальности.

## Назначение

Система предоставляет программный интерфейс для поиска физических лиц, получения их документов, адресов и дел, а также для выпуска и отката документов.

## Методы

| № | Метод | Назначение | Вход | Выход |
|---|---|---|---|---|
| 1 | searchPersonFile | Поиск лиц по критериям | Даты, пол, ФИО | Список лиц |
| 2 | getPersonDocuments | Получение документов лица | Идентификатор лица | Список документов |
| 3 | getPersonAddresses | Получение адресов лица | Идентификатор лица | Список адресов |
| 4 | getPersonCasesInfo | Получение дел лица | Идентификатор лица | Список дел |
| 5 | getDocumentDetail | Детали документа | Идентификатор документа | Детальная информация |
| 6 | getAddressDetail | Детали адреса | Идентификатор адреса | Детальная информация |
| 7 | getCountryDictionary | Справочник стран | — | Список стран |
| 8 | issueNewDocument | Выпуск документа | Данные для выпуска | Результат операции |
| 9 | rollbackIssueNewDocument | Откат выпуска | Идентификатор документа | Результат операции |

## Типы данных (кратко)

- **Лицо:** ФИО, дата рождения, пол, идентификатор
- **Документ:** серия, номер, даты, кем выдан, тип
- **Адрес:** код ФИАС, текстовое представление, тип
- **Справочник:** код, значение

## Примечания

- Протокол взаимодействия: SOAP
- Адрес сервиса и учётные данные предоставляются отдельно
- Поддерживается постраничный вывод результатов поиска
