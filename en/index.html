1. API — Interface Overview

The system exposes a programmatic interface for searching people and retrieving their documents, addresses, and case records, as well as issuing and rolling back documents.

Operations

No.OperationPurposeInputOutput
1searchPersonFileSearch for people by criteriaDate range, gender, nameList of people
2getPersonDocumentsRetrieve a person's documentsPerson identifierList of documents
3getPersonAddressesRetrieve a person's addressesPerson identifierList of addresses
4getPersonCasesInfoRetrieve a person's case informationPerson identifierList of cases
5getDocumentDetailRetrieve document detailsDocument identifierDetailed information
6getAddressDetailRetrieve address detailsAddress identifierDetailed information
7getCountryDictionaryRetrieve the country dictionary—List of countries
8issueNewDocumentIssue a documentIssuance dataOperation result
9rollbackIssueNewDocumentRoll back document issuanceDocument identifierOperation result

Data Types (Summary)

  • Person: full name, date of birth, gender, identifier
  • Document: series, number, dates, issuing authority, type
  • Address: FIAS code, text representation, type
  • Dictionary entry: code, value

Abstract Request Example

Operation: searchPersonFile
Parameters: date from, date to, gender, surname
Format: SOAP 1.1 / 1.2
Details: available under NDA

Notes

  • Communication protocol: SOAP
  • Service endpoint and credentials are provided separately
  • Search results support pagination

2. Client Application — System Overview

A software system designed to automate work with individual case files and document issuance.

Components

ComponentAbbreviationPurpose
Stationary workstationSWOperation over a local network with continuous access to the service
Mobile workstationMWOffline operation with subsequent synchronisation

Key Features

  • Search and view individual case files
  • Manage documents and addresses
  • Issue documents through defined workflows
  • Exchange data between stationary and mobile workstations in offline mode
  • Work with reference dictionaries (countries and FIAS addresses)

Technologies

  • Platform: Windows, .NET
  • UI: WPF
  • Data exchange: encrypted files and digital signatures
